# نموذج عربة Curiosity

يحتوي `curiosity.glb` على نموذج Curiosity ثلاثي الأبعاد الذي توفره NASA Science، ويُستخدم محليًا في عارض المهمة بدل رمز rover المسطح.

- المصدر: [NASA Science — Curiosity Rover, 3D Model](https://science.nasa.gov/resource/curiosity-rover-3d-model/)
- ملف glTF/GLB: https://assets.science.nasa.gov/content/dam/science/psd/mars/resources/gltf_files/24584_Curiosity_static.glb
- الإسناد الظاهر في التطبيق: NASA/JPL-Caltech

احتفظ بهذا الملف عند نقل المشروع أو نسخ ملفات الموقع المبنية؛ يعتمد عليه مشهد المهمة.
